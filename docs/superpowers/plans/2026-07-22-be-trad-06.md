> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Сделать денежный учёт paper-портфеля согласованным во всех трёх точках (buy-fill, ручное/all-закрытие, SL/TP-закрытие) по Model A, чтобы Circuit Breaker реально ловил просадку на paper.

**Architecture:** Единая точка мутации `PaperPortfolioAccountant` (balance = свободный кэш; blocked_amount = капитал открытых позиций по цене входа; equity = balance + blocked). Buy списывает (`apply_open`), любое закрытие возвращает (`apply_close`) с `×lot_size`. CB/AI не меняются (уже читают `balance + blocked`). Инертный T+1 нейтрализуется.

**Tech Stack:** Python 3, SQLAlchemy async, pytest / pytest-asyncio, structlog, Decimal-арифметика.

**Спека:** `docs/superpowers/specs/2026-07-09-be-trad-06-design.md`

## Global Constraints

- **Money model (Model A):** `balance` = свободный кэш; `blocked_amount` = Σ(`entry×lots×lot_size`) открытых позиций; `equity = balance + blocked_amount`; `available (get_balance) = balance`.
- **Инвариант согласованности:** `cost` при открытии и `cost_basis` при закрытии — одно и то же `trade.volume_rub`; `proceeds = exit_price × volume_lots × lot_mult`; `lot_mult = RiskMonitor.derive_lot_size(trade, lot_size)`. Тогда `Δequity == trade.pnl`.
- **Финансовые типы:** только `decimal.Decimal`, никаких float. Деньги — `Numeric(18, 2)`.

```python
class PaperPortfolioAccountant:
    """Единая точка денежной мутации paper-портфеля (Model A, BE-TRAD-06).

    Инвариант:
      balance         — свободный кэш (доступен под новые ордера);
      blocked_amount  — капитал в открытых позициях по цене входа;
      equity          — balance + blocked_amount (оценка по цене входа).

    Все три точки учёта (buy-fill, ручное/all-close, SL/TP-close) обязаны
    ходить через эти два метода, иначе значения снова разойдутся.
    """

    @staticmethod
    def apply_open(portfolio: PaperPortfolio, cost: Decimal) -> None:
        """BUY-fill: перевести стоимость входа из свободного кэша в блок."""
        portfolio.balance -= cost
        portfolio.blocked_amount += cost

    @staticmethod
    def apply_close(
        portfolio: PaperPortfolio,
        proceeds: Decimal,
        cost_basis: Decimal,
    ) -> None:
        """Закрытие: вернуть выручку в кэш, освободить блок по цене входа.

        Δequity = proceeds − cost_basis = realized PnL.
        """
        portfolio.balance += proceeds
        portfolio.blocked_amount -= cost_basis
        if portfolio.blocked_amount < Decimal("0"):
            logger.error(
                "paper_blocked_amount_underflow",
                session_id=portfolio.session_id,
                blocked_amount=str(portfolio.blocked_amount),
            )
            portfolio.blocked_amount = Decimal("0")
        equity = portfolio.balance + portfolio.blocked_amount
        if equity > portfolio.peak_equity:
            portfolio.peak_equity = equity
```
