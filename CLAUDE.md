# MOEX Trading Terminal — репозиторий документации

Торговый терминал для MOEX: стратегии (Blockly / текстовый шаблон / AI), бэктест,
торговля через T-Invest (paper / sandbox / real). Концепция: `Документация по проекту/idea.md`.

## Два репозитория

| Что | Где | Ветки |
|---|---|---|
| Документация (этот репо, `test`) | корень | рабочая `docs/backlog-006-strategy-builder`; в `main` — только свод через `--no-ff` |
| Код (`moex-terminal`, отдельный git) | `Develop/` | интеграционная `develop`; правила кода — `Develop/CLAUDE.md` |

Коммиты и ветки — отдельно для каждого репо, по явной команде заказчика, сообщения
на русском. `branch -D` заблокирована permission-правилом: команду удаления отдавать
заказчику текстом.

## Формат циклов и субагентов

Промпт цикла — два такта: сначала все вопросы заказчику одним блоком, затем весь
объём без промежуточных вопросов; развилки вне списка решать самому и выносить в
отчёт. Если в цикле участвуют DEV-субагенты — шаблон `Спринты/prompt_template.md`
(обязательное чтение, integration checklist, отчёт до 400 слов, `⚠️ NOT CONNECTED`
блокирует приёмку). «Создай E2E тесты» = план сценариев → инфраструктура →
написание → реальный прогон → результат passed/failed в отчёте.

Плагин `superpowers` не использовать (решение заказчика 2026-09-17): планирование —
своим подходом, TDD и разбор багов — скиллы `mattpocock-skills:*`.

Настроечные файлы `.claude/` не коммитить.
